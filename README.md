# AI Sales Analytics Assistant

基于 Streamlit + Pandas + DeepSeek API 的 AI 销售数据分析助手。

用户上传销售数据后，系统可以：

- 自动分析销售数据
- 统计销售指标
- 生成产品销售排行
- 可视化销售图表
- AI 自动生成销售分析报告
